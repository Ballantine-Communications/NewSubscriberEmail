New Start Email Sorter

Drop in the Newzware New Subscription Starts report. This pulls out each subscriber's name and email, sorts them by paper, and gives you the email addresses ready to paste into Gmail.

  1. Run the New Start report in Newzware and save it as a PDF or text file.
  2. Drop the file below, or copy the report text and paste it in.
  3. Copy each paper's emails and paste them into the Bcc line of that paper's welcome email in Gmail.
  4. Send it, with your own address in To.
